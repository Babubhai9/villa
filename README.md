# Zepvora Digital — Villa Enquiry Website

A responsive luxury villa enquiry website made with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For best results, use VS Code with Live Server.
3. Internet is required for Google Fonts, Font Awesome, AOS animations, and the demo Unsplash photography.

## Before publishing — replace these placeholders
Open `script.js` and update the `CONFIG` object:
- `whatsappNumber`: WhatsApp number with country code, digits only (example: `919876543210`)
- `phoneNumber`: your real phone number
- `email`: your business email
- `instagramUrl`: your Instagram profile

Also replace the visible phone, email, office address and social links in `index.html`.
Update the demo villa names, locations, prices, images, descriptions and amenities in the `villas` array in `script.js`.

## Included
- Home, villa listings, villa detail modal/gallery, About and Contact sections
- Search by destination, guest capacity, and price sorting
- WhatsApp enquiry links and form-to-WhatsApp flow
- Floating WhatsApp / Instagram / Call shortcuts
- Mobile bottom navigation
- Responsive layouts, reduced-motion support, scroll animations
- External AOS, Font Awesome and Google Fonts

## Important notes
- The contact form opens WhatsApp with a pre-filled message; it does not store submissions on a server.
- Prices, ratings and properties are demo content. Confirm and replace with your actual inventory.
- Villa video button is a placeholder; add real video URLs/embeds for each villa before launch.
- Add your own privacy policy, terms, verified address and booking/payment workflow if needed.
